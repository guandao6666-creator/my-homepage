# 音乐放这里

把 mp3 / m4a / ogg / wav 丢进这个目录，重新构建后会自动出现在播放器的列表里。

- 文件名就是显示的歌名（去掉扩展名），所以建议起成中文名
- 建议 128kbps 或更低的 mp3，单曲控制在 5MB 以内
- 排序按文件名，想控制顺序可以加前缀，比如「01 白饭时间.mp3」

这个 README 本身不会被当成歌曲。

## 加新曲目要注意

- 只用 **Public Domain / CC0 / CC BY** 的录音，别放流行歌和从盗版站下的文件
- CC BY 的必须署名，作者名要写在上面这张表里
- 单个文件别太大，一首 5MB 左右比较合适

## 为什么不用「下歌吧」这类站

那类站点提供的是未授权的商业音乐（站上自己写着「收费音乐免费下载」）。放进公开网站属于二次分发盗版，
版权方投诉的话 Cloudflare 会直接停站。想听可以自己本地放，别挂到线上。
