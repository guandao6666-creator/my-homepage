# 音乐放这里

把 mp3 / m4a / ogg / wav 丢进这个目录，重新构建后会自动出现在播放器的列表里。

- 文件名就是显示的歌名（去掉扩展名），所以建议起成中文名
- 建议 128kbps 或更低的 mp3，单曲控制在 5MB 以内
- 排序按文件名，想控制顺序可以加前缀，比如「01 白饭时间.mp3」

这个 README 本身不会被当成歌曲。
