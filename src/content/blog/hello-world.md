# 我的个人网站正式上线

今天，我终于完成了个人网站的第一次部署。

这个网站使用 Astro 构建，文章采用 Markdown 编写，代码托管在 GitHub，并通过 Cloudflare Pages 自动部署。

## 为什么要做这个网站？

我希望有一个属于自己的网络空间，可以记录学习过程、整理技术笔记，也可以展示自己完成的项目。

相比把所有内容都发在社交平台上，我更希望这些记录能够长期保存，并且方便查找。

## 目前使用的技术

- **Astro**：构建网站
- **Markdown**：编写博客文章
- **GitHub**：管理和保存源代码
- **Cloudflare Pages**：自动构建和部署网站

## 接下来想做什么？

1. 完善个人介绍和网站导航。
2. 记录大学课程和编程学习。
3. 展示自己完成的项目。
4. 添加分类、标签和搜索功能。
5. 绑定自己的域名。

这是一个开始。我希望以后回头看时，能看到自己一步步积累下来的东西。
