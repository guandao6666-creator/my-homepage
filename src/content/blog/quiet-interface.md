改版时我做了一件有点反直觉的事：**删东西**。

首页原本有轮播、动态背景、悬浮音乐播放器。这次我把它们全去掉了，只留下标题、一段介绍和文章列表。结果是平均阅读时长从 1 分 40 秒变成了 3 分 10 秒。

## 排版先于装饰

正文阅读体验的核心只有四件事：

1. **行宽**。中文一行 30–40 字最舒服，对应大约 640–720px 的容器宽度。
2. **行高**。正文 1.8–2.0，代码块 1.7。
3. **字号**。正文 16–17px，不要用 14px 硬塞信息密度。
4. **对比度**。正文不要用纯黑 `#000`，`#191b18` 这类带一点环境色的深色更耐读。

这四条做到了，界面就已经"不难看"了。剩下的都是加分项。

## 色彩只做一件事

我给自己定了个规则：**强调色只能出现在"需要被点击"和"正在被选中"的地方**。

于是：

- 链接用强调色；
- 当前导航项用强调色；
- 标签 hover 用强调色；
- 标题、正文、分割线一律用中性色。

规则一旦明确，配色就不再需要反复纠结。

```css
:root {
  --ink: #191b18;        /* 正文 */
  --ink-2: #41463d;      /* 次级正文 */
  --muted: #767d71;      /* 辅助信息 */
  --line: #e5e3d9;       /* 分割线 */
  --accent: #3f6b4e;     /* 唯一强调色 */
}
```

## 留白是最便宜的高级感

同一个界面，把内边距从 20px 调到 26px、把区块间距从 32px 调到 56px，观感会有明显提升——成本为零。

我现在的基本尺度：

- 页面左右内边距：26px（移动端）/ 40px（桌面端）
- 区块上下间距：56–88px
- 标题与正文之间：12–18px
- 卡片内部：20–24px

> 留白不是"空着的地方"，而是**用来分组的东西**。

## 动效只保留一种

全站只有一种动效语言：**短距离上浮 + 淡入**，200–350ms，缓动函数统一。

```css
@keyframes rise {
  from { opacity: 0; transform: translateY(14px); }
  to   { opacity: 1; transform: none; }
}
```

卡片 hover、列表进入、段落出现，都用它。一致性比花哨更有说服力。

## 深色模式要真的测

很多站点深色模式只是把背景刷黑，结果代码块、边框、图片阴影全部糊在一起。我的做法是**每个颜色变量都成对定义**，并且深色下：

- 强调色提亮（`#3f6b4e` → `#8dbf98`）；
- 分割线降对比（`#e5e3d9` → `#2b2f26`）；
- 正文避免纯白，用 `#ece9e0`。

## 最后

界面设计的终点不是"看起来专业"，而是**让人忘记界面的存在**。如果读者能一口气读完三千字而没注意到导航栏长什么样，那这个设计就成功了。
